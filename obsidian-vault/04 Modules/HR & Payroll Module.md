# HR & Payroll Module

Off by default (§4, §16) — toggle-able by admin. Covers the staff directory, pay grades, and payslips.

**No production ASP.NET controller exists for this module.** It is implemented only in the browser twin, via `hr.js`.

Touches the `Employees`, `PayrollRuns`, and `Payslips` tables.
