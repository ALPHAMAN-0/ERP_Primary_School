# §3 Hosting Constraints

Free-tier limits: 5GB website storage, 256MB dedicated RAM, 1 database, 1GB database storage, subdomain only (no custom domain), no included email accounts, no uptime guarantee, no included backups (handled in-app instead — see [[§15 Backups & Disaster Recovery]]).

Documented upgrade path: MonsterASP Premium Single, ~$1.95/mo first year ($2.50/mo renewal) — adds a custom domain, 512MB RAM, 2 databases at 2GB each, unlimited traffic, and automatic daily backups. Not selected for now; noted in the spec in case it's revisited.
