# §1 Project Overview

One composite institution — a school section and a college section under a single administration, the standard "School and College" model. Built as a real, production system for actual day-to-day use, not a demo or academic exercise. Scale: 3,000+ students across both sections. Launch approach: the full suite is built together, every module ships in v1 rather than being phased in.
