# §7 Grading & Results

Internal exams use the same GPA system as the SSC/HSC boards:

| Marks | Grade | GPA |
|---|---|---|
| 80–100 | A+ | 5.00 |
| 70–79 | A | 4.00 |
| 60–69 | A- | 3.50 |
| 50–59 | B | 3.00 |
| 40–49 | C | 2.00 |
| 33–39 | D | 1.00 |
| Below 33 | F | 0.00 |

A failing grade in any single subject fails the overall result, regardless of GPA in other subjects.
