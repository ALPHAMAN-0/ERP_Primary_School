# School College ERP

One composite institution — a school section and a college section under a single administration — serving 3,000+ students (§1). This is built as a real production system for day-to-day use, not a demo or academic exercise, and the full module suite ships together in v1 rather than being phased in one module at a time.

The requirements pin the production stack to ASP.NET MVC 5, SQL Server, and Entity Framework 6, hosted on MonsterASP's free tier — a stack GitHub Pages cannot execute a line of. Rather than settling for a screenshot prototype, the same domain rules are re-implemented as a client-side browser twin, and both sides are built and verified against the same specification, so the demo is not a mock-up of the system — it *is* the system, minus the server.

**Live demo:** hosted on GitHub Pages, no login needed — a role switcher in the bottom-left lets you sign in as any of the eight roles instantly.
